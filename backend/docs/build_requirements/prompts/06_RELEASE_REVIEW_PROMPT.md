# Final release and hackathon demo review prompt

Compare the implementation against every checkbox in `requirements/ACCEPTANCE_CRITERIA.md`. Run install/typecheck/lint/build/test commands that exist in the project. Fix critical errors and accessibility/responsive issues. Verify privacy using at least two user accounts. Confirm there are no fake buttons, secrets, unapproved integrations or false claims.

Prepare:
1. setup and deployment instructions;
2. a seeded demo flow using clearly labeled sample content;
3. a 5-minute demo script and 3-minute Q&A preparation;
4. a list of implemented features versus deferred features;
5. a short architecture explanation and key security decisions;
6. remaining risks and limitations.
Do not report success for checks that were not executed.
