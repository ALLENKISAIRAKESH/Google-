# Google+ Redesign — Frontend Application

Modern reimagining of Google+ built for engineers, researchers, and creators.

## Key Features & Differentiators
- **Google+ Circles & Audience Controls**: Target updates to Public, Specific Circles (e.g. Core Teammates, AI Lab), Specific Communities, or Private drafts.
- **Opt-In Event Instant Connect (Flagship)**:
  - Default is OFF per event.
  - Attendees explicitly choose networking goals (Teammate, Mentor, Study Partner) and visibility preferences.
  - Non-opted-in attendees are never exposed. Zero leak of private phone or email.
- **Developer Hub & Collaboration Board**:
  - Validated external coding links (GitHub, LeetCode, Codeforces, HackerRank, Portfolio) without scraping.
  - Project recruitment board with open roles, tech stack tags, and milestone task tracking.
- **Interest-Based Communities**:
  - Scoped discussions, community rules, and moderation controls.

## Running Locally
```bash
npm install
npm run dev
# The application will launch at http://localhost:5173
```

## Production Build & Verification
```bash
npm run build
# Compiles React 19 + TypeScript + Tailwind CSS bundle with zero errors
```
